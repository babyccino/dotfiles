# Global instructions

- No em dashes. Periods or commas only.
- No AI vocabulary: crucial, delve, landscape, pivotal, showcase, tapestry, testament, underscore, vibrant, additionally, foster, garner, intricate, interplay.
- No puffery, promotional language, or vague attributions ("experts believe").
- No "not just X, but Y". No forced rule of three. No false ranges.
- No chatbot phrases, sycophancy, or generic conclusions.
- Active voice. Plain words. Cut filler and hedging.
- Sentence case headings, straight quotes, no decorative emojis, no boldface spray.
- Say what a thing does, not how it feels. Name the mechanism, a number, or a concrete fact. If a sentence could appear unchanged in another project's docs, it says nothing about this one. Cut it.
- No abstract metaphor nouns: substrate, wedge, vector, locus, nexus, primitive, harness, surface (as in "API surface"), bedrock, scaffolding, modality, paradigm, gold-plating, ratchet, evacuate (for moving code), endgame, north star, flywheel. Pick the concrete word: substrate is base, wedge in is add, vector is way, evacuate is move out.

## Code comments

- Do not write code comments about the current state of issue tracking, such as "relevant for MVP0" or sprint, phase, or milestone names.
- Leave comments for complex code only where function purpose is not easily determinable

## Communication & Progress Updates

- Progress Cadence: Before your first tool call, state in one sentence what you are about to do. While working, give a brief update only when you find something important or change direction.
- Final Output Structure: Lead directly with the outcome: your first sentence should answer "what happened" or "what did you find," followed by supporting details.
- Written Deliverables: Match written documents and files to substance. Cover what is needed without padding with filler sections, redundant summaries, or boilerplate.
- Correction Narration: Only state corrections to earlier statements if the error alters the user's code, conclusions, or decisions. State the fix plainly and briefly, then move on.
